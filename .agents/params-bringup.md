# 第四阶段第一批：单页参数存储

2026-10-20更新：本机协议已统一为proto_local，UART1/2/3均支持完整17～34寄存器，
包括参数/继电器/模式/保存；原口回复。旧入口限制和proto_params/proto_dto说明
仅为历史，当前以 [统一本机协议](local-protocol.md) 为准，新功能上板待验。

后续进度：第二批已接 UART1 参数段 26～33 及保存/恢复默认/重启流程。
下文“尚未接入命令”等为第一批历史状态；当前测试见
[本机参数说明](local-params-bringup.md)。

## 当前方案

用户确认配置以出厂设置为主、很少修改，要求使用单页。现已去掉双页轮换、
备份页读取与代次管理，使用旧版 24 字节格式。两路 485 配置 4G 均已由用户
分别上板验证通过。

- 参数页：0x0801E000～0x0801E7FF，仅一页 2 KiB。
- 记录：两路波特率、欠压保护/恢复值、使能、旧 magic 和 XOR 校验。
- 保存：同页擦除后写三组双字，提交标记最后写，逐项回读校验。
- 内容与已保存记录相同时直接返回，不重复擦写。
- 无有效记录时使用默认值；单页覆写中断可能丢失原配置，下次校验失败回默认值。
- 0x0801E800 不再由参数模块读取或擦写，可另行规划。
- 应用目前仍限制为 120 KiB，0x0801E000 以上保留，旧继电器页不擦写。
  本轮没有搬动参数地址或启用旧 Bootloader。

## 分层与启动行为

Config/comm_params 提供参数类型、默认值与校验；Config/params_config 定义
固定页地址；Bsp/bsp_nv 负责页擦除和双字写入；Services/svc_params 负责记录
编解码、RAM 暂存及显式保存；App 在启动 UART 接收前恢复保存的波特率。

无记录时 UART1/2/3 保持 115200/9600/9600；如有有效旧记录，UART2/3 使用
其中的实际值（旧记录可能保存 UART3=115200）。欠压参数缺省为 10000/12000 mV、
使能 0，本批仅存储，未启动 ADC 或欠压保护动作。

波特率允许 1200/2400/4800/9600/19200/38400/57600/115200；阈值要求保护值
非零、恢复值更高，使能限定为 0/1。无效保存内容不应用。

## 接口与后续工作

- svc_params_init：启动读取，无自动擦写。
- svc_params_get/set：读取或修改 RAM 暂存值。
- svc_params_save：显式保存；UART 参数下次启动生效，不立即改变当前串口。
- svc_params_save_defaults：将默认设置写回同一页，成功后更新 RAM。
- svc_params_get_status：来源 DEFAULTS/FLASH、本次启动实际提交次数和失败次数。
  重复保存相同内容不增加实际提交次数。

API 拒绝 TX 队列非空或 GM800 正在配置的写请求。调用方仍需暂停外部 RX 业务、
处理 App 待发数据，建立静默维护窗口。Flash 擦写期间 CPU 可能停顿。

本批仍未接旧 Modbus 寄存器保存/复位命令，生产流程没有自动 Flash 写入口；
未引用的保存接口可能被链接器裁剪。下一步接本机寄存器、一次性保存请求和
先回包再保存/复位的维护流程。

## 验证

- 串口 13、DTO 8、GM800 10 场景继续通过。
- 参数 10 场景已改为单页测试：空页默认值、保存重载、旧记录启动恢复、

  相同内容不擦写、无效记录拒绝。

- 未由代理烧录。当前可回归 DTO 与两路 GM800 配置；保存掉电验收待命令接入。
- 持久化测试时核对下载工具的擦除范围，整片擦除会清除参数。

## 2026-10-20模式字段扩展

保持0x0801E000单页和原24字节记录，第二个64位字的bits40..47现在存app_mode：
0=DTO，1=HIK采集；bits48..63仍必须0。此字已在原校验覆盖范围内。
旧有效记录原预留字节为0，自然按DTO启动；其余已保存参数不丢弃，不自动改写。
DTO记录编码与旧版相同；旧固件不支持模式1记录，降级读取可能回默认值。
寄存器34独立读写（原26..33命令保持），模式实际切换成功后才更新RAM参数，
不自动保存，仍需寄存器33写56781确认保存并重启。恢复默认同时恢复DTO。
SN仍不纳入参数记录。见 [模式测试](mode-bringup.md)。

## 2026-10-20继电器接线字段扩展

寄存器35按位配置NC/NO，新增comm_params_t.relay_contact_mask，默认0、只接受0～3。
存储仍24字节/原单页，用第二个64位字bits48..55保存，bits56..63保留0。
模式bits40..47、欠压/波特率/原校验均不变，旧记录原预留字段0自然兼容。
仅56781保存，恢复默认同时将35清0；继电器自动记忆仍仅保存逻辑请求到独立原页。
上文“bits48..63必须0”现由此扩展替代。详情及指令见 [本机协议](local-protocol.md)。
