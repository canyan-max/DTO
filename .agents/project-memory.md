## 3. 分层与模块归属

| 目录 | 职责 |
| --- | --- |
| Core | CubeMX初始化、中断入口、最小装配，改动优先放USER CODE区 |
| Bsp | UART/ADC/IO/Flash/系统操作，封装HAL |
| Services | 串口队列、参数、继电器/保护、采样、采集缓存、轮询、4G配置、身份、升级标志 |
| Protocols | 本机、海康、控制器、GM800协议解析/校验/组包，不直接操作外设 |
| App | DTO/HIK业务、唯一RX消费入口、公共本机维护、模式切换 |
| Config | 引脚用途、单位/类型、默认值、Flash布局和功能配置 |

- 主要入口：`app_main`装配、`app_mode`调度、`app_local`公共命令、`app_dto`透传、`app_hik`海康/采集。
- 各串口每轮只能有一个RX消费者；`svc_poll`接收App分发的控制器帧，不自行抢读队列。
- 帧最大256字节；每口独立RX/TX缓冲，TX深度4，RX含组帧槽共5槽；UART1静默15ms，485静默50ms。
- UART发送非阻塞，TC完成才释放发送缓冲/恢复接收；UART1串行上送，禁止两路回复交叉覆盖。
- `svc_serial_discard_rx`会清完整及半包并等待新静默边界；不要在发轮询前随意调用以免吞掉快回复。
- 继电器、参数、保护和RAM SN为公共服务，不在模式或协议中复制状态。

## 4. 两种运行模式

- `COMM_APP_ENABLE_MODE=1`为生产默认，DTO/HIK均编译，由`app_mode`互斥运行。
- **0＝DTO（出厂默认）**：UART1业务同时投递两路485，两路回复独立排队返回UART1。
- **1＝HIK采集**：UART3/485口2主动轮询外设，UART2/485口1响应海康查询；本机0x14三口均支持。
- 寄存器34切换只改RAM；确认回包、三路TX排空后清旧通信/采集缓存，等待连续700ms静默再启用目标模式。
- 切换不重启，不清公共继电器请求/保护、参数和SN。20s未满足边界则取消并安全恢复原模式。
- 模式需显式56781保存；重启优先使用已保存模式，否则DTO。2～5尚未实现，写入须拒绝。
- 不要直接写Watch中的`g_mode.active`模拟切换，应走协议或`app_mode_request`。

## 5. 本机协议与数据

权威对接文档：[本机通信协议](../Docs/本机通信协议_0x14.md)。

- 地址固定`0x14`，三口两模式共用`proto_local`，原口回复；17～43可任意合法连续03读取，最大27项/59字节。
- 17/18：两路保护覆盖后的逻辑输出，05写FF00/0000；19/20为反向只读别名，不是继电器3/4。
- 21～25：10字节ASCII，DTO显示`DTO_V2.0.0`，HIK显示`HIK_V2.0.0`。
- 26/27/28：欠压保护mV、恢复mV、使能；默认10000/12000/0。
- 29/30、31/32：两路波特率高/低16位；只能用10成对写，保存重启后生效。
- 33：一次性命令，读0；56781保存，52445恢复默认，成功后重启。
- 34：模式；35：bit0/bit1为两路接线，0常闭、1常开，合法0～3、默认0。
- 36～43只读：电池电压、电流、SOC、剩余容量、标称容量、温度1、太阳能电压/电流。
  电压/电流为0.01V/0.01A，容量0.01Ah，温度0.1℃；37和41有符号，其他无符号。
- 剩余容量由`svc_poll`统一估算：32位乘法`nominal_10mah * soc_percent / 100`，不足0.01Ah向下截断。
  200Ah×89%=178Ah（17800/0x4588）；HIK和本机39使用同一缓存。缺容量或SOC为0则结果0。
- 电池/太阳能分别7s过期；无有效外设缓存仍正常回包，测量值填0，不把本机ADC当外设电池电压。
- 兼容01读取17～20：每项一个字节，**不是标准Modbus线圈位打包**。
- CRC低字节在前、寄存器高字节在前；CRC错误/短包不回，合法非法请求返回异常。

## 6. 保存、继电器与欠压

- 参数仅用`0x0801E000`单个2KiB页，低频/出厂配置，不恢复双页备份。
- 原24字节记录不变：word0存两路32位波特率；word1存阈值、使能、模式（bits40～47）、
  接线mask（bits48～55），bits56～63必须0；word2存magic/校验。旧扩展字节0自然对应DTO/常闭。
- 参数/模式/接线不自动保存。56781／52445先原口ACK、全部TX完成，再暂停RX、写入/校验、成功重启；失败不反复擦写。
- 恢复默认同时恢复两路9600、阈值10000/12000、使能0、DTO和接线0，不擦继电器独立记忆。
- 继电器逻辑请求自动保存在`0x0801F000`，ACK及TX完成后维护，不重启。
- `svc_relay`统一：`logical = UV ? 0 : requested`，`GPIO = logical XOR contact_bit`。
  `requested`是记忆请求，`output`是保护后的逻辑输出，`gpio`是实际电平；35改变映射，不改请求或自动写继电器页。
- 有效ADC持续低于等于保护阈值3s触发；持续高于恢复阈值3s恢复最新请求。
  无效采样重置计时并保持保护状态；任务停顿>=1s不算连续有效时间。禁用时解除保护覆盖。

## 7. 外设轮询与海康

详细说明：[采集与海康协议](../Docs/采集与海康协议说明.md)。

- `proto_controller`纯编解码，`svc_poll`单事务。先EVE，连续5s无有效回复后切换尝试SZS。
- 查询起发间隔>=1s，TX完成后响应窗口600ms，失败静默600ms，排队超时2s。
- EVE地址1：03/9001/14固定容量；实时04/3100/2太阳能、3110/1温度、311A/1 SOC、3200/2状态、331A/3电池V/I。
- SZS地址1：03/E002/10固定容量、0100/9实时、00FD/1状态。
- 固定信息失败不阻塞实时数据，容量保持0；维护恢复/换型后重读固定信息。
- EVE电流331B低字+331C有符号高字按32位组合；SZS状态回复仅1寄存器，不能读取不存在的第二项。
- 电池各采样组要有效且新鲜才发布；太阳能独立更新，不能用新太阳能掩盖电池组过期。
- 海康支持A5的03/0F/0C/0D及5A/A3。温度缓存/海康采用℃×10＋2731，本机41减2731。
- 海康SN固定16字节，仅RAM，短内容由发送方左补0x00（不是字符0），读回不去零；启动清空、切模式保留。
  写ACK固定`DD A3 00 00 00 00 77`；不随56781保存，但真实重启自然清空RAM。

## 8. GM800配置

详细说明：[4G配置](../Docs/4G模块配置说明.md)。

- 两路485发送ASCII `AT+CLOUD=`＋20位数字可触发，两模式共用；鉴权后缀沿已确认旧配置，不复制设备身份默认值。
- 当前共23步：保留旧21条，CLOUD之后、保存之前增加`AT+ICCID?\r\n`、`AT+IMEI?\r\n`。
- 相邻起发>=200ms且前条TX完成/应答通过；+++等a，a等+ok，普通AT等完整OK行。
- 流式解析支持分段/多行，回显/编号不代替OK，ERROR优先；普通超时2s、两次保存各5s，会话90s。
- 失败停后续步骤，不自动重试/重配；只等外部重新发指令。成功保留两次AT+S和AT+Z。
- 原始回复及失败步骤提示只回发起485口；日志满丢日志，不跳过ACK校验；收尾500ms后排空TX退出。
- 配置期间暂停DTO/采集；本机保存/恢复默认及重复配置等业务丢弃、不排队，结束后重发。
- `CONFIRMED`表示23条应答通过，不代表程序已验证平台在线；ICCID/IMEI仅日志，不入寄存器/Flash。

## 9. Flash布局与引导

详细说明：[引导接入](../Docs/引导接入说明.md)。

| 用途 | 地址范围／标志 |
| --- | --- |
| Boot代码预留 | 0x08000000～0x08002FFF，实际Boot工程由用户维护 |
| 标志页 | 0x08003000～0x080037FF；升级0，正常0x55BB |
| APP | 0x08003800～0x0801DFFF；长度0x1A800 |
| 参数 | 0x0801E000～0x0801E7FF |
| 原备用页 | 0x0801E800～0x0801EFFF，不访问、不擦写 |
| 继电器记忆 | 0x0801F000～0x0801F7FF |

- BootLoad为严格8字节ASCII `42 6F 6F 74 4C 6F 61 64`，无0x14前缀、CRC、CRLF或ACK，两模式三口共用。
- 排空所有TX并暂停RX后，仅擦标志页、写0回读、系统复位；TX异常/20s超时或Flash失败不复位、不自动重试。
- `bsp_boot`核对实际装载区Base/Limit及VTOR：Base/VTOR均3800、含RW装载副本的镜像不超E000才可写。
- `app_init`调用`svc_boot_init`，安全布局且标志低32位不是55BB时维护正常标志，同值不擦；失败记数不循环复位。
- 当前链接与下载范围已由用户设为3800/1A800。main的USER区补头文件，HAL_Init前设置VTOR、DSB/ISB，恢复旧Boot关闭的全局中断。
- 下载APP用按扇区擦除，避免整片擦掉Boot及存储。Boot升级端实际擦除范围要与用户Boot工程保持一致。
