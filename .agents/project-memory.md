## 源码与配置事实
- 主工程：MDK-ARM/comm_convert.uvprojx，目标 comm_convert。
- STM32G070KBT6，裸机 HAL；CubeMX 包 STM32Cube FW_G0 V1.6.3。
- ARM Compiler 5.06 update 6；Keil.STM32G0xx_DFP.2.1.0。
- 芯片 Flash 128 KiB、SRAM 36 KiB；MDK 应用限制 120 KiB，起始地址
  0x08000000；0x0801E000 以上保留，不作为程序链接空间。
- 根目录 Core/Src/main.c 在 USER CODE 区接入 app_init/app_task；启动失败或
  喂狗失败进入 Error_Handler。初始化完成后开启 4G/两路 485 电源。
- 时钟：HSI → PLL 64 MHz，AHB /4，HCLK/CPU 16 MHz。
- UART1 为 115200 8N1；UART2/3 为 9600 8N1，硬件 DE 高有效；
  新工程无 UART DMA，参考 Program 使用逐字节中断收发。
- 当前 App 在启动接收前恢复有效保存记录的 UART2/3 波特率；无有效记录
  保持 9600/9600，UART1 始终 115200。旧记录可能保存了 UART3=115200。
- UART1 TX/RX：PA9/PA10；UART2 TX/RX/DE：PA2/PA3/PA1；
  UART3 TX/RX/DE：PA5/PB9/PB1。硬件连线仍需上板核对。
- ADC1：PA0，12 位、连续转换、无过采样、无 DMA。
- TIM14：PSC=1599、ARR=1999；TIM16：PSC=1599、ARR=9999。
  按当前 16 MHz 定时器时钟分别为 200 ms、1 s，业务未启动它们。
- IWDG：分频 256、Reload=1025；已接入主循环处理后的喂狗。
- GPIO 标签：LED1/2/3、GM800FVDDEN、VCCEN1/2、G2ROUT1～4。
  旧代码把电源使能和继电器定义为高有效、LED 低有效，未在新工程验证。
